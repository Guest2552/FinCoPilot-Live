## 📖 About The Project
**FinCoPilot** is an advanced, AI-driven personal finance SaaS platform designed to act as a sophisticated, autonomous wealth advisor. It bridges the gap between simple expense tracking and algorithmic wealth management by utilizing Batch LLM-based transaction analytics, predictive financial modeling, and an autonomous LangChain agent capable of executing complex debt-reduction and investment strategies.

## ✨ Key Features

* **🧠 Multi-Model AI Advisor (LangChain):** A conversational, context-aware financial agent powered by a dynamic router allowing users to seamlessly switch between Groq (Llama 3), OpenAI (GPT-4o), Google Gemini, Anthropic Claude, and xAI Grok. 
* **📊 Batch LLM Transaction Analytics:** Upload raw CSV bank statements from any major institution. The AI dynamically maps columns, reverse-engineers opening balances, and categorizes hundreds of transactions using semantic analysis to detect spending leaks.
* **🌍 Dynamic Regional Market Benchmarking:** Automatically detects the country of origin for stock holdings (via Yahoo Finance tickers) and compares 30-day portfolio percentage growth against respective local indices (e.g., S&P 500, NIFTY 50, SSE Composite).
* **📈 10-Year Wealth Forecaster & Spending Matrix:** Calculates True Net Worth, Average Daily Burn, and Savings Runway, projecting future wealth accumulation using real-time compounding algorithms.
* **📉 Proactive Debt Management:** Analyzes outstanding loan balances and interest rates to recommend optimal payoff strategies (Avalanche Method) before suggesting market investments.
* **📑 Executive AI PDF Dossiers:** Automatically generates highly professional, color-coded financial reports using ReportLab, complete with a personalized executive summary written dynamically by the AI.
